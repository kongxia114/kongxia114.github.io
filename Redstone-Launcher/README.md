# Redstone Launcher

一个用 Python + PyQt6 写的 Minecraft 启动器。

[![Release](https://img.shields.io/github/v/release/kongxia114/Redstone-Launcher)](https://github.com/kongxia114/Redstone-Launcher/releases)
[![License](https://img.shields.io/github/license/kongxia114/Redstone-Launcher)](LICENSE)
[![Python](https://img.shields.io/badge/python-3.11+-blue)](https://www.python.org/)

## 简介

Redstone Launcher 是一个开源的 Minecraft 启动器，支持：
- 多版本管理
- Forge / Fabric 安装
- 账户管理
- 多语言 / 多主题

## 下载

从 [Releases](https://github.com/kongxia114/Redstone-Launcher/releases) 下载最新版。

## 特性

- ✅ 扫描本地版本
- ✅ 下载原版游戏
- ✅ 安装 Forge / Fabric
- ✅ 账户管理（离线 / 正版）
- ✅ 多语言（中 / 英 / 繁 / 日 / 俄）
- ✅ 深色 / 浅色主题

## 开发

### 环境

- Python 3.11+
- PyQt6

### 运行

```bash
pip install -r requirements.txt
python main.py
