# Mosslight Launcher 2 · 官网交接清单

> 给新会话用：整段贴过去就行。目标是做一个**介绍用的官网**（单页即可）。

## 1. 一句话定位

Mosslight Launcher 2：用 C# / WPF 重写的 Minecraft 启动器。**一个 1.4 MB 的 zip，解压出来一个 exe**，
装原版、装加载器、装整合包、搜社区资源、管账户、开游戏，全在一个窗口里。

- 仓库：https://github.com/kongxia114/Mosslight-Launcher-2
- 许可：GPL-3.0（页脚必须注明并链 LICENSE）
- 当前版本：2.11.8（`CHANGELOG.md` 是更新内容的**唯一来源**）
- 平台：Windows x64；运行前提 **.NET 10 桌面运行时（x64）**（不是 SDK、不是 ASP.NET Core）
- 语言：简体 / 繁體 / English / 日本語 / Русский

## 2. 三条卖点（首屏就讲这三件）

1. **轻**：Release 里只有一个约 1.4 MB 的 `win64.zip`，解压就一个 `Mosslight.exe`，更新一次也就几秒。
2. **全**：原版 / Forge·NeoForge·Fabric·Quilt·OptiFine / 整合包（`.mrpack` 和拖进来都行）/
   Modrinth 社区资源 / 离线与第三方账户 / 外观与动效 / 自动更新，不用装第二个软件。
3. **稳**：核心引擎拿 1.0.0 的 Python 实现当金标准**逐值比对**，自检 1302 项全过。

## 3. 功能清单（8 条，去掉 emoji，配 Lucide 图标）

| 中文 | 一句话 |
|---|---|
| 启动游戏 | 按版本要求自动挑 Java、按物理内存推荐值、解压 natives；运行中按钮变红，一点强制结束整个进程树 |
| 下载原版 | 走 BMCLAPI 镜像，多线程 + 重试 + 熔断切官方源，已下好的认 sha1 跳过 |
| 一键装加载器 | Forge / NeoForge / Fabric / Quilt / OptiFine / LiteLoader |
| 一键装整合包 | `.mrpack` 或拖 zip 进窗口：解包 → 装原版 → 装加载器 → 压平成一个版本文件夹 |
| 社区资源 | 模组 / 整合包 / 数据包 / 资源包 / 光影包（来源：Modrinth），按版本 + 类型筛，滚到底续加载 |
| 账户 | 离线档案、LittleSkin 网页授权 / 账号密码、自建 Yggdrasil；一账号多角色随时切，皮肤头像自动拉 |
| 外观 | 深色 / 浅色 / 跟随系统、自定义强调色、背景图五种铺法、卡片透明度、7 档入场动效（可整体关掉） |
| 多语言 + 自动更新 | 5 种语言切换立刻生效；单文件替换 + SHA256 校验 |

## 4. 视觉（直接抄，别自己调色）

- **强调色族（默认绿）**：`accent #5EC269` / `fill #3F8F4B` / `hover #4DA25A` / `pressed #357D40` /

  仙人掌 `#4CAF50`、金锭 `#D9A03A`、紫水晶 `#A06BD6`、红石 `#C94F4F`

- **调性**：深色为主、卡片圆角 10、留白克制；**绝对不用 emoji，只用 Lucide 线性图标**
