02 / 功能

常用的几个功能

设置只有这一处，功能也都在主窗口里。

01

启动游戏

按版本要求挑 Java，按物理内存给推荐值，解压 natives。游戏跑起来后按钮会变红，点一下可以结束整个进程树。

自动挑 Java强制结束
02

下载原版

版本清单从 BMCLAPI 镜像获取，多线程下载、失败重试；镜像连续出问题就切官方源。已经下好的文件会校验 SHA-1，跳过重复下载。

BMCLAPISHA-1 校验
03

一键装加载器

Forge、NeoForge、Fabric、Quilt、OptiFine、LiteLoader 都能装。Forge、NeoForge 这些要跑官方安装器，启动器会先把需要的库下好。

6 种加载器官方安装器
04

一键装整合包

支持 .mrpack，也支持把 zip 直接拖进窗口：解包、装原版、装加载器，压平成一个版本文件夹。

.mrpack拖拽安装
05

社区资源

模组、整合包、数据包、资源包、光影包，来源都是 Modrinth；可以按游戏版本、加载器和分类筛，滚到底自动加载。

Modrinth5 类资源
06

账户

离线档案、LittleSkin 网页授权或账号密码、自建 Yggdrasil。一个账号下的多个角色可以随时切换，皮肤头像会自动拉。

LittleSkinYggdrasil
07

外观

深色、浅色、跟随系统，自定义强调色，背景图五种铺法，卡片透明度，7 档入场动效。动效可以整体关掉。

7 个预设色7 档动效
08

多语言 + 自动更新

简中、繁中、English、日本語、Русский，切换后立刻生效；自动更新只替换一个 exe，并做 SHA256 校验。

5 种语言SHA256

04 / 下载

下载
安装

下载、解压、双击就能用。以后更新时覆盖 Mosslight.exe 就行，不用重新安装。

下载最新版 查看更新日志

会跳转到 GitHub Releases · 当前版本 v2.12.8

Windows 10 1809+ / x64 GPL-3.0
  1. 01 下载 win64.zip 从 GitHub Releases 下载最新版。
  2. 02 解压到可写目录 桌面或 D:\Games 都行。
  3. 03 双击 Mosslight.exe 第一次启动会扫描 Java，稍等几秒。
RUNTIME

运行前提

.NET 10 Desktop Runtime · x64

不是 SDK，也不是 ASP.NET Core Runtime，装一次桌面运行时就行。

  • Windows 10 1809 及以上
  • 64 位处理器
  • 解压后再运行，别在压缩包里直接双击
  • 只从 GitHub Releases 下载，每个包校验 SHA256
下载不走第三方镜像
